# NexOLT - Professional OLT Management Software

**NexOLT** is a powerful, lightweight, and user-friendly OLT Management Software explicitly designed for Internet Service Providers (ISPs). It streamlines network administration by allowing seamless configuration and monitoring across multiple OLT platforms from both desktop and mobile environments.

## 📱 Platform Support
* **Windows OS** (PC / Desktop Client)
* **Android OS** (Mobile App)

## ✨ Key Features
* **Multi-Vendor Compatibility:** One software to manage various OLT brands.
* **Real-time Monitoring:** Check ONU status, RX/TX power levels, and uptime.
* **Easy Configuration:** User-friendly UI for rapid provisioning and troubleshooting.
* **Cross-Platform Sync:** Switch smoothly between your PC and Android device.

## 🛠️ Installation & Setup
1. **For Windows:** Download the `.exe` file, run the installer, and follow the on-screen setup wizard.
2. **For Android:** Download the `.apk` file. Ensure "Install from Unknown Sources" is enabled in your device settings before installing.
3. Open the app, configure your server credentials, and start managing your OLT network instantly!
